01 — Features

What bliss actually does.

Nine things your server would otherwise invite six different bots for — with the logs, permissions and cleanup handled in the same place.

VoiceMaster

Voice channels that create and clean themselves.

Members join a hub channel and get their own temporary room, plus a control panel for everything they'd otherwise need a moderator for. When the room empties, it's gone.

  • Join-to-create hub, with public and private categories
  • Lock, hide, permit and reject individual members
  • Rename, set a limit, transfer ownership or claim an abandoned room
  • Automatic cleanup — nobody has to tidy the channel list

AI tools

Answers in the channel, not in a browser tab.

Logging & security

A record of everything, and a door that holds.

Audit logs for the events you usually reconstruct from memory, alongside anti-raid, anti-spam, auto-moderation and verification. The log tells you what happened.

  • Anti-raid and anti-spam rules, plus auto-moderation
  • Verification for new members before they can post
  • Per-channel command toggles, per-role command permissions

04 — Setup

Three things, then you're done.

Everything is configured with slash commands. There is no web dashboard to sign into and no config file to write.

  1. 01

    Authorize the bot

    Pick a server, review the permissions Discord shows you, and approve. The default invite requests administrator so every feature works immediately — you can uncheck it and grant only what you plan to use.

    Server Settings → Integrations manages access later
  2. 02

    Run /voicemaster setup

    Choose a hub channel and the categories new rooms should appear in. Members join the hub and get a temporary channel with its own control panel; empty rooms are deleted.

    Public and private categories supported
  3. 03

    Set your rules

    Decide where commands can run, who can use them, and what gets logged. Aliases, channel toggles and role restrictions are all individual commands, so changes are reversible.

    /disablecommand · /restrictcommand · /alias

05 — FAQ

Questions worth asking.

Anything missing is answered in the support server, usually the same day.

Is bliss free?

The core bot is free to use, and AI tools include a daily usage allowance. A small number of quality-of-life extras — such as staying in a voice channel when idle — are premium. There is no credit card step to get started.

What permissions does it need?

The standard invite requests administrator, which is the simplest way to make every feature work out of the box. If you'd rather keep the bot on a short leash, uncheck administrator on Discord's consent screen and grant the specific permissions you need: manage channels for VoiceMaster, manage messages for moderation, and so on.

Does bliss read every message?

It only processes messages in channels where it is active, and only to respond, moderate or log as configured. It is not trained on your messages. If you'd rather it stayed out of a channel, turn commands off there with /disablecommand.

Do I need a dashboard?

No. Setup, permissions, logging and VoiceMaster are all configured from Discord with slash commands. The command index documents each one, including its arguments and the permissions it requires.

Can I use it in just one or two channels?

Yes. Commands can be disabled per channel or restricted to specific roles, and aliases keep the ones you do use short. Nothing is enabled by default in channels you haven't configured.

Where do I report a bug or ask for a feature?

The support server is the fastest route. Bug reports with the command and a screenshot get looked at first.

Is bliss affiliated with Discord?

No. bliss is an independent third-party app built on Discord's API and developer terms. Discord is a trademark of Discord Inc.
